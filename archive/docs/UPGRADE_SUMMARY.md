## 🚀 使用方法

### 方法1: 版本选择器（推荐）
```bash
python gui_demo.py
```
提供友好的图形界面选择要使用的GUI版本。

### 方法2: 直接启动现代化版本
```bash
python run_modern_gui.py
```

### 方法3: 使用原始启动方式
```bash
python tianyancha_treeview.py
```
默认启动现代化版本，如需原始版本请修改main函数。
