# 天眼查Cookies更新指南

## 🔍 问题确认

通过实际网络请求测试，我们发现：

- **实际获取的页面：** 天眼查登录页面 (170,603 字符)
- **预期的页面：** 公司详情页面 (245,693 字符)
- **关键CSS类名：** 全部缺失 ❌
- **页面内容：** 包含登录表单和验证码

**结论：Cookies已过期，需要更新才能访问公司详情页面。**

## 🔑 如何获取新的Cookies

### 方法1：从浏览器获取 (推荐)

1. **打开浏览器**，访问 https://www.tianyancha.com
2. **登录您的天眼查账号**
3. **登录成功后**，按 `F12` 打开开发者工具
4. **切换到 Network 标签页**
5. **刷新页面** (按F5)
6. **找到第一个请求** (通常是主页面请求)
7. **点击该请求**，在右侧面板找到 `Request Headers`
8. **复制 Cookie 字段的完整内容**

### 方法2：从浏览器设置获取

1. **Chrome浏览器：**
   - 地址栏点击锁图标 → Cookie → tianyancha.com → 查看所有Cookie
   - 复制所有Cookie并按格式组合

2. **Edge浏览器：**
   - 设置 → Cookie和站点权限 → 管理和删除Cookie → tianyancha.com
   - 复制所有Cookie值

## 🚨 重要注意事项

1. **Cookies有时效性** - 通常几小时到几天后会过期
2. **不要分享Cookies** - 包含您的登录信息，请勿泄露
3. **定期更新** - 如果再次出现登录页面，重复上述步骤
4. **账号安全** - 确保您的天眼查账号安全

## 🔄 自动化Cookies更新 (高级)

如果您经常使用，可以考虑：

1. **使用Selenium自动登录** - 自动获取cookies
2. **设置cookies监控** - 检测到过期时自动提醒
3. **使用配置文件** - 将cookies存储在单独的配置文件中

## 📞 如果仍有问题

如果更新cookies后仍然无法正常工作：

1. **检查账号状态** - 确保天眼查账号正常
2. **检查网络连接** - 确保能正常访问天眼查网站
3. **检查反爬虫** - 天眼查可能有新的反爬虫措施
4. **联系技术支持** - 提供详细的错误信息
